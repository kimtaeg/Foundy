# 생활인구 도로 표시 기준

2026-11-21 변경. 데이터 추가나 DB 변경 없이 기존 250m 격자·도로 자료의 표시 방식을 수정했다.

| 단계 | 전체 | 성별 | 연령대 | 시작 색상 |
| --- | --- | --- | --- | --- |
| 매우 적음 | 500명 미만 | 250명 미만 | 50명 미만 | 아주 연한 노랑 `#FFEDB3` |
| 적음 | 500~1,000명 미만 | 250~500명 미만 | 50~200명 미만 | 연한 노랑 `#FFE08A` |
| 보통 | 1,000~2,000명 미만 | 500~1,000명 미만 | 200~500명 미만 | 진한 노랑 `#FFB547` |
| 많음 | 2,000~4,000명 미만 | 1,000~2,000명 미만 | 500~2,000명 미만 | 주황 `#F56B32` |
| 매우 많음 | 4,000명 이상 | 2,000명 이상 | 2,000명 이상 | 빨강 `#CC3030` |

모두 250m 격자 공개 인원수이며 각 구간의 시작값은 포함한다.
전체 탭(내국인·외국인 포함), 성별 탭, 연령대 탭은 각각 고정된 기준을 사용한다.
남녀는 같은 성별 기준, 10세 미만 및 10대부터 70세 이상까지는 같은 연령대 기준이다.
시간·반경·지도 위치·개별 연령이 바뀌어도 경계값을 다시 계산하지 않는다.
예를 들어 8명은 모든 연령에서 매우 적음이고, 전체 3,889명은 많음이다.
서로 다른 탭의 같은 색은 같은 인원수를 뜻하지 않는다. 범례에 현재 탭의 기준과 경계를 표시한다.
서비스 표시 기준이며 공식 혼잡도·안전 기준이나 도로별 실측 보행량은 아니다.

이전 전체 기준의 1,000·2,000·4,000명 경계를 복원하고 500명 미만을 매우 적음으로 나눴다.
성별 기준은 전체 경계의 절반으로 정한 고정 표시 구간이다. 실제 남녀 인원수를 나누거나 보정하지 않는다.
기존 2026-11-15 연령별 자료를 공개시간 평균으로 계산하면 10~70대의 98.0~99.6%가
1,000명 미만이어서 연령대는 낮은 인원수를 구별하는 50·200·500·2,000명 경계를 유지한다.
이 연령대 기준을 전체에 적용하면 성수 기본 중심 반경 500m의 표시 도로 96.57%가 많음·매우 많음이었다.
분리 후 전체의 같은 두 구간은 21.71%, 최상위 구간은 3.43%다.
이는 공개시간 평균과 지도 확대 수준 4의 원자료 도로 개수 기준이며 화면의 픽셀 면적 비율은 아니다.
실행 중 최대값이나 백분위로 기준을 재정규화하지 않는다.

실제 지도 도로는 하나의 Canvas 레이어에 그린다.
현재 분류의 0명 및 네 경계값에 배치한 색상 앵커 사이를 연속 보간하며,
연결점은 인접한 공개 격자별 값을 한 번씩 반영한 색상을 공유한다.
각 도로 내부에는 자기 격자의 색상 앵커를 유지한다.
투명도는 완성된 레이어에 한 번 적용하여 교차점·둥근 끝점의 색이 반복해서 진해지지 않게 한다.

그라데이션은 연결부의 시각적 표현이다. 적은 값은 연한 노랑이고 인원수가 커질수록 주황·빨강으로 이어진다.
범례 막대는 기존처럼 5개의 분리된 색상 칸이다. 툴팁의 인원수와 단계, 반경 합계는 원래 공개값을 사용한다.
공개 0은 수치 0의 색으로, 비식별은 회색으로 표현한다.
비식별은 접점의 인구값 보간에서 제외하며, 원본이 없는 도로와 떨어진 도로 사이를 새로 연결하지 않는다.

계산과 렌더링 책임은 `levels.ts`, `road-gradient.ts`, `road-canvas.ts`,
`useRoadPopulationOverlay.ts`, `RoadPopulationLayer`로 나뉜다.
`POPULATION_CUTS[category]`를 도로·범례·툴팁에 함께 전달한다. 색상/등급/도로 보간 함수는
기준을 필수 인자로 받아 특정 분류의 기본 기준을 몰래 적용할 수 없게 한다.
분류 변경 시 도로 보간의 memo도 갱신하며 지도와 Canvas는 유지한다.
지도 좌표 변환과 레이어 생명주기는 [Kakao AbstractOverlay API](https://apis.map.kakao.com/web/documentation/#AbstractOverlay)를 사용한다.

검증 명령: `npm run test:market:data`, `npm run test:market`, `node tests/population-age-map.mjs`.
분류별 경계값·전체 3,889명의 비포화·남녀/연령 내 공통 기준·연속 보간·비식별·실제 Canvas 갱신·8명 툴팁을 확인한다.
