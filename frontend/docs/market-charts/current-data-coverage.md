# 현재 데이터로 가능한 상권 그래프

**새 데이터 수집·구매·생성, DB 테이블·컬럼 추가 없이 기존 자료만 가공한다.** [참고 보고서](https://m.nicebizmap.co.kr/explorer/summary)의 구획·요약·그래프 방식을 참고하되, 해당 사이트의 매출·고객·비용 수치는 가져오지 않는다.

## 현재 DB 확인

2026-11-20 **21:34 KST**, 기존에 제공받은 DB 연결로 `REPEATABLE READ READ ONLY` 트랜잭션에서 테이블 목록·행 수·캐시 source/최상위 필드명만 확인했다. 개인 행 내용은 읽지 않았으며 DB를 변경하지 않았다. [읽기 전용 확인 결과](existing-db-data-audit.json)

기존 스키마의 JSONB 필드에 데이터를 넣을 수 있다는 사실과 실제 데이터가 존재한다는 것은 다르다. 특히 빈 `api_cache`를 매출·인구 통계가 이미 있는 것으로 취급하지 않는다. 현재 프론트는 DB를 직접 읽지 않고 시연 상태/localStorage와 포함된 정적 파일을 사용한다.

## 집계와 표시 기준

1. 모든 생활인구 그래프는 **기존 2026-11-15 공개 데이터**만 사용한다. 도로 조각마다 같은 격자 값을 반복 더하지 않으며, 기존 분석과 같이 중심점이 선택 반경에 포함되는 격자를 집계한다.
2. `number`의 0은 실제 공개값이다. `"*"`는 전부 비식별, `null`/행 없음은 미제공, `[합계, 공개 수, 비식별 수]`는 일부 비식별이다. 미제공·전부 비식별을 0으로 채우거나 그래프에서 관측값처럼 연결하지 않는다.
3. 공개시간 평균은 공개값이 있는 시간만 분모에 포함한다. 반경 값은 **격자별 공개시간 평균의 합**이다. 24시간 합계를 일일 순방문자로 표시하지 않는다.
4. 성별·연령은 **내국인 분류**이고 서로 독립적이다. `전체 + 남성 + 여성`, `내국인 + 연령대`처럼 총계와 세부집단을 중복 합산하지 않는다.
5. 비식별·누락과 서로 다른 관측시간 때문에 세부집단 값의 합이 별도 전체 파일의 값과 다를 수 있다. 비율을 사용한다면 **표시된 공개값 내 비중**으로 이름 붙이고, 총인구 구성비처럼 단정하지 않는다.
6. 시간대별 비교는 공개된 범위의 비교다. 가장 큰 값은 ‘공개값이 가장 높은 시간’으로 표현한다. 공개 범위가 달라질 수 있으므로 실제 방문 피크나 영업시간 추천으로 확정하지 않는다.
7. 점포·가격 그래프에 **예시** 표기를 유지한다. 예시 범위 밖 빈 목록은 ‘표시할 예시 없음’이며 실제 점포가 0개라는 뜻이 아니다.
8. 가격은 있는 세 지점만 범위 그래프로 표시한다. Q1/Q3나 구간별 빈도, 평균, 표본수, 가격 정규분포를 임의 생성하지 않는다.

## 데이터 변경 범위

이번 확인은 조회·가공 가능성 검토다. DB 쓰기·마이그레이션, 외부 데이터 신규 수집, 참고 사이트 숫자 반입은 수행하지 않았다. 차트 구현은 기존 원본 파일·예시 상수·사용자 입력의 파생 값만 사용하면 되며, DB 확장은 필요하지 않다.
