## 실패 응답과 저장

- [x] [페이지 조회 오류](../tests/api-error-handling.mjs)에서 대시보드·리포트·체크리스트·서류함·지원사업·마이페이지·상권 분석의 503 메시지가 정확히 보이고, 본문 없는 오류 응답의 대체 문구와 조회 재시도를 확인했습니다. 첫 세션 확인 500 복구, 사용 중 401 세션 정리, 로그인 429·500과 회원가입 409도 확인했습니다.
- [x] [브라우저 통합 테스트](../tests/api-integration.mjs)에서 격리된 FastAPI·PostgreSQL을 사용했습니다. 가게 등록·영업 조건·체크리스트·개업일·서류 상태·리포트 선택 및 후속 작업·프로필·알림에는 실패 응답을 주입하고, 이어서 실제 저장과 재조회도 실행했습니다.
- [x] [지원사업](../tests/grants-integration.mjs), [알림](../tests/notification-errors.mjs), [AI 상담](../tests/chat-api-integration.mjs)에 지연과 실패 응답을 주입해 안내와 복구를 확인했습니다. FastAPI 예외 처리와 CORS는 별도로 실제 HTTP 경계에서 테스트했습니다.
- [x] 카카오 승인 도메인에서 실제 지도와 위치를 확인했습니다. 주소 입력 단계의 오류와 재시도는 SDK 응답 대역으로 검증했습니다. 지도 SDK는 테스트용 포트 3102를 거부하므로 세부 지도 테스트는 브라우저 주소를 `http://localhost:3000`으로 유지하고 앱 응답만 격리된 로컬 빌드에서 가져왔습니다. HTTP 200에 잘못된 생활인구 JSON을 반환해도 지도를 유지하고, 다시 시도하면 데이터가 복구됨을 확인했습니다.

## 실행 환경과 범위

- [x] `localhost:3000`의 테스트 가게로 실제 DB 연동 상태에서 대시보드·리포트·체크리스트·서류함·마이페이지·상권 분석 조회, K-Startup 공고 1건 갱신, 실제 AI 답변·근거·DB 이력 복구를 확인했습니다.
- [x] 백엔드 전체 테스트 `597 passed, 15 skipped`. 건너뛴 테스트는 별도 실제 LLM·공공 API 환경을 요구하거나 법령 시드가 필요한 사례입니다. 외부 연동 실측은 위의 실제 환경 흐름을 참고하세요.

- [ ] 모든 Props 조합의 개별 렌더링과 외부 제공자의 전체 실패 조합은 남아 있습니다. 이번 실행의 화면·컴포넌트 연결과 예외 조합은 링크한 테스트에서 확인할 수 있습니다.
