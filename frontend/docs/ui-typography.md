# Foundy 글자 크기와 대비 규칙

## 크기와 역할

| 역할 | 기준 | Tailwind |
| --- | --- | --- |
| 본문·도움말·버튼·내비게이션 | 14–16px | `text-sm`, `text-base` |
| 입력·선택·텍스트 영역 | 16px | `text-base` |
| 짧은 배지·날짜·단위·차트 축 | 최소 12px | `text-xs` |
| 카드 제목 | 16–20px | `text-base`–`text-xl` |
| 페이지 제목 | 24px 이상, 화면 폭에 맞춰 조절 | 반응형 제목 스타일 |

12px은 짧은 보조 표기에만 사용한다. 문장 형태의 설명은 14px 이상,
줄높이 1.6–1.8을 기본으로 한다. 공간이 부족하면 줄바꿈·배치 변경·탭 스크롤로
해결하며 글자를 줄이지 않는다. 입력 필드는 16px을 유지한다.

## 색상

- 기본 글자: neutral-800/900. 설명·날짜·단위: neutral-600 (`#525252`).
- 브랜드 기본색: `rgb(16, 126, 125)` (`#107e7d`).
- 연한 배경 위의 작은 강조 글자: `text-foundy-primary-ink` (`#0c6564`).
- 경고: `--amber: #8a5200`, 위험: `--red: #b4232d`.
- 읽은 알림·완료 항목·취소 상태는 문구, 취소선, 상태 표식으로 구분한다.
  텍스트를 포함한 컨테이너 전체에 opacity를 낮추지 않는다.
- placeholder도 neutral-600을 사용한다.

일반 텍스트 대비 목표는 4.5:1 이상이며, 크고 굵은 제목은 3:1 이상이다.
기준: [W3C WCAG 2.2 Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
12px 최소 크기는 이 프로젝트의 사용자 요구사항이다.

## 적용 위치

- `src/app/globals.css`: 기본 본문 16px, small 14px, placeholder와 색상 토큰.
- `src/lib/styles/recipes.ts`: 공통 UI 역할별 크기와 상태 스타일.
- 각 컴포넌트: Tailwind 클래스로 개별 역할과 반응형 배치 지정.

폰트 크기를 다시 덮어쓰는 `font` shorthand 유틸리티는 사용하지 않는다.
날짜 안의 small 등 12px 메타데이터는 `text-xs`로 명시한다.

## 검증 범위

1440px·390px·320px에서 로그인, 대시보드, 리포트, 체크리스트·달력,
서류함, 지원사업 카드·리스트·마감 달력, 마이페이지, 등록,
상권 분석의 4개 탭을 검사한다.

실제 렌더링 크기, 단색 배경의 글자 대비, 가로 넘침을 함께 확인한다.
Kakao SDK 내부 지도 글자·지도 이미지와 비활성 컨트롤은 대비 검사 범위에서
제외한다. 이 검사는 전체 WCAG 준수 인증을 의미하지 않는다.
