# 생활인구 지도 데이터

인구 기준일: **2026-11-15**. 출처: 서울특별시·KT, 서울시 통신데이터.
도로: 원본 프로젝트 기준 OSM 2026-11-14 추출본, © OpenStreetMap contributors (ODbL).

`foot-traffic-map` 프로젝트의 `public/data/`에서 가져온 정적 스냅샷이다. 원본 JSON 662개를 바이트 변경 없이 복사했다. `quality.json`에 생성 시각, 기준일 일치 여부, 비식별 및 경계 조인 누락 정보가 있다. 내국인 경계 조인 누락 1개를 임의 좌표로 대체하지 않는다.

- `pop-*.json`: 격자별 24시간 공개값. 숫자 0은 실제 공개 0, `*`는 비식별, `null`/키 없음은 원본 행 없음이다. `[합계, 공개 행 수, 비식별 행 수]`는 부분 공개 상태를 보존한다.
- `roads/index.json`과 타일: 공식 250m 경계로 분할한 도로 조각. 격자 ID와 연결한다.
- 성별/연령대는 내국인 자료만 사용한다. 전체는 내국인·장기외국인·단기외국인의 공개값 합계다.
- 화면의 일평균은 **공개시간 평균**이다. 전부 비식별인 시간을 0으로 채우지 않으며, 모든 시간이 공개된 24시간 평균과 구분한다.
- 도로 색은 해당 격자의 생활인구 추정치다. 도로별 실측 보행량·실시간 유동인구로 해석하면 안 된다.

수집/재생성은 원본 `foot-traffic-map/scripts/build-grid.mjs`와 `build-roads.py`에서 수행한 다음, 기준일과 quality 검증을 마친 자산 묶음 전체를 교체한다. 서로 다른 날짜의 파일을 섞지 않는다. 현재 앱은 기준일 선택·신규 날짜 수집 API를 제공하지 않는다.
