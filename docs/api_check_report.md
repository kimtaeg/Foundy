## 1. 카카오 주소 → 건축HUB 건축물대장

### 호출 결과

| 단계 | 요청 | 상태 | 시간 |
|---|---|---|---|
| 주소 검색 | `dapi.kakao.com/v2/local/search/address.json` | 200 | 약 200ms |
| 표제부 | `BldRgstHubService/getBrTitleInfo` | 200 (totalCount 2) | 약 140~240ms |
| 층별개요 | `BldRgstHubService/getBrFlrOulnInfo` | 200 (totalCount 21) | 약 140~290ms |
| 지역지구구역 | `BldRgstHubService/getBrJijiguInfo` | 200 (totalCount 4) | 약 110~380ms |

오퍼레이션 이름 세 개는 모두 정상 응답이 와서 맞는 것으로 확인했습니다.

### 필요한 값이 오는가

| 항목 | 결과 | 실제 값 |
|---|---|---|
| 법정동코드 `b_code` | O | `1120011500` → `sigunguCd=11200`, `bjdongCd=11500` |
| 본번·부번·산 여부 | O | `0289` / `0010` / 산 아님 (`platGbCd=0`) |
| 좌표 | O | `127.0571, 37.5451` |
| 표제부 주용도 | O | 주건축물 `제1종근린생활시설` (기타: 업무시설, 제1.2종근린생활시설) |
| 1층 용도명·면적 | O | 소매점 293.06㎡ / **휴게음식점 107.2㎡** / 금융업소 137.07㎡ / 부동산중개업소 45.11㎡ |
| 지역지구 | O | 준공업지역, 지구단위계획구역 |
| 위반건축물 표기 | **X** | 세 응답 전체에서 "위반"·"viol"이 들어간 필드나 값이 없음 |

### 우리가 쓸 필드

- 카카오: `documents[0].address.b_code`, `main_address_no`, `sub_address_no`, `mountain_yn`, `address_name`, `documents[0].x`, `y`, `road_address.building_name`
- 표제부: `mainAtchGbCdNm`, `mainPurpsCdNm`, `etcPurps`, `useAprDay`, `grndFlrCnt`, `ugrndFlrCnt`, `totArea`, `bldNm`, `platPlc`, `newPlatPlc`, `regstrKindCdNm`
- 층별개요: `flrGbCdNm`, `flrNo`, `flrNoNm`, `mainPurpsCdNm`, `etcPurps`, `area`, `mainAtchGbCdNm`, `dongNm`
- 지역지구구역: `jijiguGbCdNm`, `jijiguCdNm`, `reprYn`, `etcJijigu`
- 공통 결과 코드: `response.header.resultCode`, `resultMsg`, `response.body.totalCount`

### 문제와 대응

| 문제 | 대응 (설계 문서 반영) |
|---|---|
| 위반건축물 필드가 없음 | 8장 확인 목록 1번 결론: `building_violation`은 항상 `unknown` + "세움터에서 건축물대장 열람" 안내 |
| 1층에 용도가 다른 칸이 4개 있음 (층 단위로는 우리 가게 칸을 특정할 수 없음) | 되묻기에 "1층 중 어느 칸인지(면적 또는 현재 용도)"를 추가하거나, 1층 용도 목록을 모두 보여 주고 사용자가 고르게 한다 |
| 부속건축물(주차타워)도 `flrGbCdNm=지상`, `flrNo=1`로 오고 `flrNoNm`은 "지층" | `mainAtchGbCdNm == "주건축물"`로 걸러야 한다 |
| 표제부가 주건축물·부속건축물 2건으로 옴 | 주용도는 `mainAtchGbCdNm == "주건축물"` 행을 쓴다 |
| 지역지구구역이 같은 값 2쌍으로 중복됨 | `jijiguCd` 기준으로 중복을 제거한다 |
| 키 오류는 JSON 요청이어도 XML로 올 수 있음 | `tools/building.py`는 JSON 파싱 실패 시 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 등 문구로 키 문제를 구분해야 한다 |

**판정: 핵심 동작.** 1층에 실제로 `휴게음식점` 칸이 있어서, S1(휴게음식점 용도 + 주류 판매) 데모를 실제 데이터로 보여 줄 수 있습니다. 다만 업종 판단은 규칙 묶음이 해야 합니다.

## 4. 카카오 카테고리 검색 (CE7 카페, 반경 300m)

### 호출 결과

| 단계 | 상태 | 시간 |
|---|---|---|
| 주소 → 좌표 | 200 | 약 130ms |
| 카테고리 검색 page 1~3 (`size=15`, `sort=distance`) | 200 ×3 | 각 약 90~240ms |

### 필요한 값이 오는가

| 항목 | 결과 |
|---|---|
| 가게 이름 `place_name` | O |
| 거리 `distance` (m) | O (`x`, `y`를 보낼 때만 옴) |
| 좌표 `x`, `y` | O |
| `place_url` | O |
| 한 번에 몇 건 | 한 페이지 최대 15건, 최대 3페이지 **45건**까지 (`pageable_count=45`) |

- 반경 300m 안 카페는 `total_count=54`개인데, 목록으로 받을 수 있는 것은 45건까지입니다.
- 가장 가까운 곳은 같은 건물의 "빽다방 성수역점"(0m)입니다.

### 우리가 쓸 필드

`meta.total_count`, `meta.pageable_count`, `meta.is_end`, `documents[].place_name`, `distance`, `x`, `y`, `place_url`, `category_name`, `road_address_name`, `id`

### 문제와 대응

| 문제 | 대응 |
|---|---|
| 최대 45건까지만 받을 수 있음 | "동종 업소 수"는 `meta.total_count`(54)로 표시하고, 지도 마커만 45건으로 제한한다. 전부 필요하면 `rect`로 범위를 나눠 조회한다 |
| `phone` 필드가 있음 | 쓰지 않으니 저장할 때 `[가림]` 처리했다 |
| 설계 문서는 반경 업소 목록을 소상공인 상가정보 API로 가져오게 되어 있었음 | **결정(2026-11-19): 지도·동종 업소 수는 카카오 로컬만 쓴다.** 상가정보 API는 쓰지 않는다 (아키텍처 문서 5장 `places` 도구로 반영). 상권 분석(경쟁 강도·프랜차이즈 비율)은 이 값에서 규칙으로 계산한다 |

**판정: 상권 분석에 사용 (시간되면).** 지도와 동종 업소 수, 경쟁 강도 계산에 바로 쓸 수 있습니다. 카테고리는 카페(CE7)에 더해 음식점(FD6)도 같은 방식으로 조회하며, 메뉴·가격·유동인구·개폐업 추이는 제공하지 않으므로 화면에서 "데이터 없음" 또는 [예시]로 표시합니다.

## 설계 문서에 반영할 것

`docs/아키텍처_인프라.md` 기준입니다. (2026-11-19 프로토타입 반영: 8장 확인 목록 1·상권·지도 항목은 `[x]`로 갱신, 상가정보 API는 제외, 소셜 로그인·기관 전화번호 항목 추가)

- **8장 확인 목록 1번 (위반건축물):** 표기 없음 → `building_violation = unknown` + 세움터 열람 안내 (확인 완료)
- **8장 확인 목록 2번 (법령 API):** 로컬 IP에서는 동작. Railway 서버 IP는 배포 후 확인 필요 (아웃바운드 IP 고정 여부 포함)
- **5장 `address` 도구:** 행정안전부 도로명주소 대신 카카오 주소 검색 하나로 법정동코드·번·지·좌표를 모두 얻을 수 있습니다. 그러면 `JUSO_API_KEY`, `JUSO_COORD_API_KEY`가 필요 없어집니다.
- **5장 타임아웃:** 설계는 5초. 측정값은 가장 오래 걸린 건축법 시행령 본문도 1초 안쪽이라 5초로 충분합니다.
- **3-4 환경변수:** 문서는 `KIPRIS_API_KEY`, 루트 `.env.example`은 `KIPRIS_KEY`, `SEOUL_KEY`로 서로 다릅니다. 이름을 하나로 맞춰야 합니다.
- **시연 주소:** 루트 `.env.example`의 `DEMO_ADDRESS=성수동2가 300-1`은 성수이로 113(성수동2가 289-10)과 다른 지번입니다. 하나로 맞춰야 합니다.
