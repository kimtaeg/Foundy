> 범위의 기준 문서. Must 항목이 끝나기 전에는 범위 밖 기능(로그인, 상권 분석, 다른 업종 등)을 만들지 않는다.
> 예선 마감: **2026-11-23(월) 17:00**

## 1. 한 줄 정의

카페·음식점을 여는 청년을 위한 **창업 전 사전 점검 에이전트**.
업종·주류 판매 여부·주소(층)·가게 이름·개업 예정일을 입력하면 건축물대장·법령·상표를 조회해
"계약 전 꼭 확인 / 개업 전 할 일 / 운영 중 주의" 리포트와 개업 역산 일정표를 만든다.
문제가 나온 항목은 판정만 던지지 않고 **결과 카드**(결론·선택지·추천·대신 만든 결과물·사용자가 할 일 1개)로 보여줘서, 사용자는 결정 한 번으로 끝낸다.

### 결과 카드 (문제 항목의 표시 형식)

| 칸 | 내용 |
|----|------|
| 결론 | 한 줄, 결과 중심의 쉬운 말 |
| 안 하면 생기는 일 | 돈·시간 기준 |
| 선택지 | 대응 방안 비교 (기간·금액은 근거가 있을 때만 숫자, 없으면 "확인 필요") |
| 추천 | 기본 선택 하나와 이유. `[추천대로 진행]` 한 번으로 가게 정보·체크리스트 반영 |
| 대신 만든 결과물 | 구청 문의 문자, 임대차 특약 문구, 열람 링크, 신고서류 초안 |
| 당신이 할 일 | 1개와 소요 시간 (결정·서명·방문·보내기) |

## 5. 데모 시나리오

| # | 입력 | 기대 결과 |
|---|------|-----------|
| S1 | 휴게음식점 용도 층 + 주류 판매 | `위반 소지 높음`: 일반음식점 필요, 건물 용도 불일치. 결과 카드: 선택지(술 빼고 시작 / 용도변경 / 후보 자리 변경), 추천, 구청 문의 문자·특약 문구, 할 일 1개 |
| S2 | 등록 상표와 비슷한 가게 이름 | `확인 권장`: 유사 상표 목록. 결과 카드: 이름 바꾸기(겹치지 않는 후보) / 그대로 진행 선택지와 추천 |
| S3 | 메뉴 설명에 효능 표현 | `확인 권장`: 광고 문구 위반 소지. 결과 카드: 문구 수정안 선택지 |
| S4 | 문제없는 입력 | 위반 항목 없이 할 일과 일정표만 표시. 결과 카드 없음 |
